# Cattr developer documentation

These guides document the legacy Cattr **Laravel backend** and **Vue 2 frontend** extension APIs. They are maintained alongside the source code, but examples should be checked against the current implementation before use.

- [Frontend](frontend/README.md): module APIs, context, routing, stores and components
- [Backend](backend/README.md): access control, events, filters and integration modules
- [HTTP API reference](https://docs.cattr.app/api/): generated separately and published on GitHub Pages

For contribution workflow and signing requirements, see [CONTRIBUTING.md](../../../CONTRIBUTING.md).
