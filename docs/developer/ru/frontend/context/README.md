# Context

> Работа с API Cattr используя модуль
- - -

__context__ является основным интерфейсом взаимодействия с API Cattr. Любые взаимодействия с ядром Cattr должны производиться только через контекст. Простыми словами, __context__ является сущностью, которая и представляет создаваемый модуль. Более подробно о методах взаимодействия с ядром через контекст смотрите в подразделах.
