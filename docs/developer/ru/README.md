# Документация разработчика Cattr

Эти руководства описывают API расширения существующего Cattr на **Laravel и Vue 2**. Документы находятся рядом с кодом, но примеры необходимо проверять по актуальной реализации.

- [Frontend](frontend/README.md) — модули, контекст, маршрутизация, Vuex и компоненты
- [Backend](backend/README.md) — права доступа, события, фильтры и интеграционные модули
- [HTTP API](https://docs.cattr.app/api/) — справочник API, который по-прежнему публикуется в GitHub Pages

Требования к изменениям и подписям коммитов описаны в [CONTRIBUTING.md](../../../CONTRIBUTING.md).
