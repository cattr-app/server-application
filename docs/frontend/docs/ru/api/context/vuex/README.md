# Vuex Storage

Из-за использования единого дерева состояния, все глобальные данные приложения оказываются помещены в один большой объект. По мере роста приложения, хранилище может существенно раздуться.

Чтобы помочь в этой беде, Vuex позволяет разделять хранилище на модули. Каждый модуль может содержать собственное состояние, мутации, действия, геттеры и даже встроенные подмодули.

Подробнее о модулях Vuex <https://vuex.vuejs.org/ru/guide/modules.html>.

## Регистрация модуля

```javascript
context.registerVuexModule({
	state: {
		//...
	},
	mutations: {
		//...
	},
	getters: {
		//...
	},
	actions: {
		//...
	}
});
```

Состояние модуля будет доступно как `store.state.myModule`, где `myModule` название вашего модуля.

## Инициализация модуля

Для инициализации модуля при запуске приложения вы можете воспользоваться методом `init`.

```javascript
context.registerVuexModule({
	actions: {
		init(context) {
			//...
		}
	}
});
```

?>Метод `init` автоматически выполняется в контексте данного Vuex модуля при загрузке приложения.
