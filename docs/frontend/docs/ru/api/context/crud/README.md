# CRUD

> Создание CRUD страниц

- - -

CRUD страницы позволяют конечному пользователю взаимодействовать с сущностями, полученными с бэкенда.

CRUD страница является отдельным конфигурационным объектом и не привязывается к контексту. Изменение содержимого страницы при [перехвате инициализации модуля](ru/api/module-loader-interceptor/) возможно при помощи изменения требуемого объекта конфигурации (свойство meta) внутри массива свойства routes экземпляра context внутри перехватчика.

В __CRUD__ входят 3 вида страниц:

1. View - страница, на которой __отображается__ (но не может быть изменена) информация о той или иной сущности
2. Edit - страница, на которую передается информация о сущности для ее дальнейшего изменения и сохранения
3. New - страница, которая предоставляет конечному пользователю веб-форму для создания сущности и ее сохранения.

Данные для CRUD получаются при помощи описанного в сервис-классе метода `getItem`, а сохраняются при помощи описанного внутри класса метода `save` (подробнее см. в разделе [Сервис классы](ru/api/service-class/)).

Итоговая страница представляет из себя объект конфигурации Vue Router, непосредственная конфигурация содержимого страницы находится внутри свойства meta объекта конфигурации. Подробнее о конфигурации Vue Router см. в разделе [Маршрутизация](ru/api/context/routing/)

# Создание CRUD. Метод createCrud

CRUD страница описывается отдельной сущностью и, в отличии от остальных элементов взаимодействия с контекстом, в итоге является конфигурацией Vue Router.

Чтобы получить интерфейс описания CRUD, необходимо вызвать метод `createCrud` объекта __context__.

```javascript
/**
 * Create CRUD instance, which can be exported to RouterConfig
 *
 * @param label
 * @param id
 * @param serviceClass
 * @param filters
 * @param defaultPrefix
 * @param pages
 * @returns {Crud}
 */
createCrud(label, id, serviceClass, filters, defaultPrefix = '', pages = { edit: true, view: true, new: true }) {
    const crud = new Crud(label, id, serviceClass, filters, this, defaultPrefix, pages);
    return crud;
}
```

1. __label__ - отображаемое название CRUD страницы. Обратите внимание, что Vue автоматически попытается перевести значение данного поля, если для его содержимого будет найден сопоставимый перевод. Более подробно см. в разделе [Локализация](ru/api/context/localization/)
2. __id__ - идентификационный ключ страницы, используется для создания маршрутов и идентификации.
3. __serviceClass__ - [сервис класс](ru/api/service-class/), отвечающий за получение, маппинг и сохранение данных
4. __filters__ - добавляют возможность управления Query Builder'а на бэкэнде. Всегда должен быть объектом. Необязательный параметр. Доступные свойства объекта:
    * __with__ - массив, описывает подключаемые к модели требуемой сущности eloquent-отношения (имена отношений)
    * __withCount__ - массив, описывает количество сущностей, связанных с требуемой моделью переданными в данный параметр именами отношений.
5. __defaultPrefix__ - префикс роутера по-умолчанию для данной страницы. Необязательный параметр.
6. __pages__ - страницы, которые будут доступны при создании CRUD инстанса. ___Является объектом___. По умолчанию включены все три: edit, view, new.

`createCrud` возвращает экземпляр класса Crud.

После создания CRUD-инстанса, его конфигурацию нужно передать в маршруты. Для этого используется метод `getRouterConfig`, который возвращает объект конфигурации для Vue Router.

```javascript
const crud = context.createCrud('Sample Page', 'sample-page', SomeServiceClass);
```

Для того, чтобы загрузить данные о странице в модуль, передайте объект, полученный из `getRouterConfig` в метод `addRoutes` объекта __context__ (подробнее см. [Маршрутизация](ru/api/context/routing/))

```javascript
context.addRoutes(crud.getRouterConfig());
```

# Управление сгенерированными страницами

Интерфейс CRUD предоставляет разработчику возможность изменения и надстройки всех трех типами создаваемых страниц (new, edit, view). Каждая страница представлена отдельным интерфейсом, доступ к которому можно получить по соответствующему свойству у экземпляра CRUD, возвращаемого методом `createCrud`.

```javascript
const view = crud.view; // Интерфейс view-страницы
const edit = crud.edit; // Интерфейс edit-страницы
const new = crud.new; // Интерфейс new-страницы
```

?>Страницы new и edit описываются Vue-компонентом EditView, страница view описывается Vue-компонентом ItemView. Более подробнее смотрите в разделе Advanced API.

## `addField`

Основной элемент взаимодействия со страницей - метод `addField`.

```javascript
/**
 * @param fieldConfig
 * @returns {New}
 */
addField(fieldConfig) {
    this.addToMetaProperties('fields', fieldConfig, this.getRouterConfig());
    return this;
}
```

В качестве аргумента `fieldConfig` метод принимает __массив__, состоящий из объектов - сущностей, которые описывают то или иное поле для формы. Для описания поля в объекте доступны следующие свойства (* указаны обязательные параметры)

1. __key__* - ключ поля, должен соответствовать ключу из полученных данных. По нему модель определяет, какие данные сопоставить с каким полем.
2. __label__ - отображаемое имя поля. Обратите внимание, что при рендере Vue автоматически попытается перевести данное поле, если для него были созданы переводы. Подробнее смотрите в разделе [Локализация](ru/api/context/localization/)
3. __type__ - frontend-тип поля. Может быть представлен следующими типами (подробнее о типах см. ниже)
    * __text__ (либо input)
    * __textarea__
    * __select__
    * __number__
    * __resource-select__
4. __required__ - устанавливает значение поля required для HTML-поля. Тип: boolean. По-умолчанию false
5. __frontendType__ - применим только для типа text/input. Устанавливает значение HTML-атрибута type для HTML поля. _Обратите внимание, что для типа number необходимо использовать тип поля number для свойства type._
6. __options__ - массив. Используется для указания списка доступных опций для типа поля select. Является массивом объектов с двумя свойствами - value и label.
    * __label__ - отображаемое имя опции
    * __value__ - передаваемое значение опции
7. __displayable__ - boolean-параметр, который определяет, будет ли поле видимо на frontend'е или нет. По-умолчанию false.
8. __render__ - параметр, описывающий кастомное поле (подробнее смотрите в разделе [Кастомные поля](ru/api/context/crud/custom-fields/)). __Является функцией__, которая принимает в себя два параметра - экземпляр [__$createElement__](https://vuejs.org/v2/guide/render-function.html) и объект, содержащий в себе параметры контроля ввода
    * __inputHandler__ - функция-обработчик ввода в поле, устанавливается как обработчик события v-on:input для редактируемого поля.
    * __currentValue__ - текущее значение для данного поля. Если значения нет или оно не установлено, то в качестве значение данного свойства передается пустой объект
    * __focusHandler__ - функция-обработчик фокуса поля, должен устанавливаться как обработчик события v-on:focus для редактируемого поля
    * __blurHandler__ - функция-обработчик блюра редактируемого поля. Устанавливается как обработчик события v-on:blur для редактируемого поля.
    * __field__ - объект, которые описывает конфигурацию текущего поля.

Пример конфигурации `addField`:

```javascript
const fieldsToFill = [
    {
        key: 'id',
        displayable: false
    },
    {
        label: 'field.name',
        key: 'name',
        type: 'text',
        placeholder: 'field.name',
        required: true
    },
    {
        label: 'field.description',
        key: 'description',
        type: 'textarea',
        required: true
    },
    {
        label: 'field.important',
        key: 'important',
        type: 'select',
        options: [
            {
                value: 0,
                label: 'control.no'
            },
            {
                value: 1,
                label: 'control.yes'
            }
        ]
    }
];

crud.new.addField(fieldsToFill);
crud.edit.addField(fieldsToFill);
```

Итоговая конфигурация полей страницы хранится внутри объекта `meta` объекта конфигурации роутера, которую возвращает метод `getRouterConfig` объекта `crud`.

?> Обратите внимание, что для разных типов страниц могут быть различные конфигурации полей.

## `addPageControls`

Метод `addPageControls` позволяет управлять элементами контроля страницы (например, кнопки "Назад" или "Удалить". По-умолчанию frontend-контроллером является HTML-кнопка.

!> Следует учитывать, что на страницах типа Edit и New автоматически создается кнопка "Сохранить", которая вызывает метод save у __сервис-класса__.

```javascript
/**
 *
 * @param config
 * @returns {New}
 */
addPageControls(config) {
    this.addToMetaProperties('pageData.pageControls', config, this.getRouterConfig());
    return this;
}
```

Параметр `config` метода `addPageControls` принимает в себя массив объектов, которые описывают определенный frontend-контроллер страницы. В объекте описания доступны следующие свойства

1. __label__ - отображаемое имя контроллера. Обратите внимание, что Vue автоматически попытается перевести значение данного поля, если для его содержимого был найден перевод. Более подробнее см. в разделе Локализация
2. __type__ - frontend-тип кнопки. Более подробно вы можете узнать на странице документации UI-кита, который использует Cattr. Доступные значения для данного поля (визуальное отображение см. ниже)
    * primary
    * success
    * error
    * warning
    * info
      <img src="/assets/images/buttons.png">
3. __icon__ - иконка, которая будет отображена перед значением поля label. О доступных иконках можно узнать [тут](https://at-ui.github.io/at-ui/#/en/docs/icon)
4. __onClick__ - свойство, описывающее callback-функцию для обработки события нажатия на кнопку. В качестве первого аргумента данная функция принимает текущий контекст элемента __EditView.vue__ (_this_, с доступным в нем Vue Router и Vuex), в качестве второго - значение полей текущей сущности (записи).
5. __renderCondition__ - _callback-функция_, которая должна возвращать __boolean__-значение. В случае, если значение является false, то frontend-контроллер (кнопка) не будет отображена пользователю. Данное свойство используется для определения возможности отображения контроллеру пользователю. В качестве единственного аргумента функция принимает текущий контекст __EditView.vue__ (_this_, с доступным в нем Vue Router и Vuex). _Необязательный параметр_, true по-умолчанию.

## addToMetaProperties. Управление мета-данными конфигурации Vue Router

Если есть необходимость напрямую изменить мета-данные итоговой конфигурации Vue Router (которую, в свою очередь, возвращает метод `getRouteConfig`), вы можете воспользоваться методом `addToMetaProperties` у экземпляра требуемой страницы (new, edit или view)

?> Обратите внимание, что каждая страница имеет свой собственный конфиг. Изменение мета-конфигурации на одном типе странице не повлияет на мета-конфигурацию другой.

```javascript
/**
 * @param property
 * @param data
 * @param routerConfig
 */
addToMetaProperties(property, data, routerConfig) {
    _.set(routerConfig.meta, property, data);
}
```

Доступные параметры метода (все из них обязательны)

1. __property__ - имя свойства объекта. Если необходимо изменить или добавить вложенное свойство, разделяйте их через запятую. Так, например, чтобы изменить значение свойства `attribute`, которое, в свою очередь, является дочерним для свойства `parentAttribute`, необходимо в качестве значения данного параметра передать строку __"parentAttribute.attribute"__
2. __data__ - содержимое, которые требуется задать для свойства property
3. __routerConfig__ - текущий routerConfig страницы. Можно получить у экземпляра страницы при помощи метода `getRouterConfig`.

## Защита маршрутов страниц

Для того, чтобы ограничить возможность некоторых групп пользователей доступа к создаваемым страницам, вы можете использовать [Защиту маршрутов](ru/api/context/routing/guard/).

Для того, чтобы защитить создаваемые страницы, при помощи метода `addToMetaProperties` задайте значение мета-параметра `permissions`. В качестве значение должно выступать имя правила, которое должно быть у пользователя. Если правила у пользователя нет, доступ к странице будет запрещен.

Более подробно о правилах доступа читайте в документации к backend-составляющей.

# getRouterConfig. Получение конфигурации Vue Router и добавление конфигурации в контекст

Метод `getRouterConfig` должен быть вызван у итогового экземпляра CRUD (который возвращает метод createCrud). После всех взаимодействий и настроек отдельных типов страниц, данный метод вернет массив объектов, которые представляют из себя объекты конфигурации Vue Router (подробнее см. [здесь](https://router.vuejs.org/)).

```javascript
const crudRouterConfig = crud.getRouterConfig(); // Array<Object>
```

Для того, чтобы добавить итоговую конфигурацию в модуль, необходимо передать результат выполнения метода getRouterConfig в метод `addRoute` вашего `context`.

```javascript
context.addRoute(crudRouterConfig); // Добавление конфигурации маршрутов в модуль
```

?>После добавления конфигурации маршрутов в контекст, созданные страницы будут доступны с префиксом __\<Module_Router_Prefix\>/\<Crud_Router_Prefix\>__ по следующим URI:<br><br>
Для страницы New - /new </br>
Для страницы Edit - /edit/\<id\> <br>
Для страницы View - /view/\<id\> <br>
<br>
__Module_Router_Prefix__ - префикс роутера по-умолчанию, взятый из ModuleConfig __Crud_Router_Prefix__ - префикс для страниц, который устанавливается параметром `defaultPrefix` у метода `createCrud` <br>
__id__ - id требуемой сущности. Сопоставляется с результатом вызова метода `getIdParam` у __сервис-класса__. Подробнее см. в разделе [Сервис классы](ru/api/service-class/)
