# Маршрутизация

- - -

Для работы с маршрутизацией используется официальная библиотека Vue Router. Подробнее о Vue Router <https://router.vuejs.org>

## Добавление нового маршрута

Метод `addRoute` принимает в качестве параметра объект конфигурации Vue Router.
Доступны любые свойства, описанные в документации Vue Router.

```javascript
context.addRoute({
    path: '/users',
    name: 'users',
    component: () => import('./views/Users.vue')
});
```

?>По умолчанию неавторизованные пользователи не имеют доступа к маршруту. Подробнее [Защита маршрутов](/ru/api/context/routing/guard/?id=Авторизованные-пользователи)
