# Защита маршрутов

---

Защита маршрутов позволяет ограничить доступ к маршрутам на основе определенного условия, например, только авторизованные пользователи с определенным набором прав могут просматривать страницу.

## Авторизованные пользователи

По умолчанию неавторизованные пользователи не имеют доступа к маршруту.
Для того, чтобы разрешить неавторизованным пользователям доступ к маршруту необходимо добавить поле `auth` со значением `false` в свойстве `meta` объекта конфигурации Vue Router.

```javascript
context.addRoute({
  path: "/users",
  name: "users",
  meta: {
    auth: false,
  },
  component: () => import("./views/Users.vue"),
});
```

## Права

Для того, чтобы ограничить пользователям доступ к компоненту, необходимо определить метод renderCondition из которого вернуть булевое значение.
Можно проверить права доступа пользователя с помощью __$can__.

```javascript
renderCondition({ $can }, item) {
    // User always can view project's tasks
    return false;
},
```

```javascript
renderCondition({ $can }, item) {
    return $can('updateMembers', 'project', item);
},
```
