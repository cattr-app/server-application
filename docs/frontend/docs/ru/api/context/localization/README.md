# Локализация

> Добавление или изменение локалей Cattr
- - -

Cattr поддерживает интернационализацию "из коробки". Локализация приложения осуществляется путем добавления в систему файла с необходимыми переводами. Cattr использует пакет [vue-i18n](https://kazupon.github.io/vue-i18n/) для поддержки интернационализации. Файлы переводов хранятся в формате json. Мы рекомендуем придерживаться следующего алгоритма локализации:

1. Любой текст представляется в виде "кодов". Например, Dashboard именуем как __navigation.dashboard__.
2. В файле локализации устанавливается "перевод" для данного кода. Например, для английского языка мы добавляем запись (подробнее см. далее):

```json
{
    "navigation": {
        "dashboard": "Dashboard"
    }
}
```

# Добавление/изменение локалей

Для того, чтобы добавить/изменить локаль, необходимо создать json файл, содержащий в себе информацию о переводах. Мы рекомендуем придерживаться формата "кодов", так, другим разработчикам или командам будет проще локализировать тот или иной модуль. Название файла должно соответствовать коду языка, на который направлена локаль. Например, __en__ для английского языка, __ru__ для русского и т.д.

?> Обратите внимание, что "из коробки" Cattr поддерживает только английский, русский и датский языки. При необходимости добавления новой локали в систему - воспользуйтесь методом `addLocaleCode` (подробнее смотрите ниже).

## `addLocalizationData`

Добавление локали осуществляется при помощи метода addLocalizationData. В качестве аргумента метод принимает объект, в котором ключи - коды локалей, а значения ключей - объект с переводами. Так как Cattr использует пакет [vue-i18n](https://kazupon.github.io/vue-i18n/) для интернационализации, то "из коробки" приложение поддерживает __группировку__. Так, например, объект следующего содержания (пример для английской локализации) ...

```json
{
    "navigation": {
        "dashboard": {
            "timeline": {
                "label": "Timeline", 
                "user_time": "Total Time",
            }
        }
    }
}
```

... будет преобразован плагином vue-i18n в следующий объект:

```json
{
    "navigation.dashboard.timeline.label": "Timeline",
    "navigation.dashboard.timeline.user_time": "Total Time"
}
```

> Согласно примеру выше, строка ___"navigation.dashboard.timeline.label"___ будет отображаться на английской локали как ___"Timeline"___, а ___"navigation.dashboard.timeline.user_time"___  как ___"Total Time"___

Однако, если в модуле нет необходимости использовать группировку, можно использовать стандартные переводы "строка к строке" (пример для русской локализации):

```json
{
    "Sample String": "Образец строки"
}
```

> Согласно примеру выше, строка ___"Sample String"___ будет отображаться на российской локали как ___"Образец строки"___

Чтобы добавить переводы в приложение, в каталоге с модулем создайте json файл c переводами (см. пример выше) и передайте его содержимое в качестве значения объекта с кодом языка:

```javascript
context.addLocalizationData({
        en: require('./locales/en'),
        ru: require('./locales/ru'),
    });
```

> В данном примере подразумевается, что в каталоге создаваемого модуля имеется каталог `locales` c файлом `en`. Рекомендуется использовать похожую структуру каталогов в проекте.

Как видно в примере, `addLocalizationData` принимает в качестве параметра объект, в котором ключ - это код локали, а значение - объект с переводами

?> Мы рекомендуем использовать __json__-файлы для хранения локалей, однако разработчик волен выбирать тот формат, который принят в его проекте.

!> Учтите, что если в систему добавляется язык, который изначально отсутствовал в Cattr (любой, кроме английского, датского и русского), в систему необходимо добавить локаль при помощи метода `addLocaleCode`

## `addLocaleCode`

"Из коробки", Cattr поддерживает датский (dk), русский (ru) и английский (en) языки. Чтобы добавить поддержку нового языка, который не предусмотрен системой изначально, необходимо воспользоваться методом `addLocaleCode`. После добавления, новая локаль будет доступна для выбора пользователем.
В качестве первого аргумента метод принимает код локали, в качестве второго - отображаемое имя локали.

```javascript
context.addLocaleCode('de', 'Denmark');
```
