  PVC {{ include "cattr.pvcClaimName" . }} (ReadWriteOnce, strategy Recreate). Do not scale it.

{{- if .Values.mysql.enabled }}

Built-in MySQL {{ $fullname }}-mysql is a single-node DEMO database without backups.
Use database.host with an external MySQL/MariaDB for production.
The first install runs setup as a post-install hook: do not use --wait for that install
(the app Pods wait for the migrations that only run after the wait), use
  kubectl -n {{ .Release.Namespace }} rollout status deploy/{{ $fullname }} --timeout 15m
